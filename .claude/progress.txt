## Codebase Patterns
- Use ./.venv/bin/python, not bare python3
- Harden the spike code; do not rebuild it
- Never treat spike-quality labels in data/cases/ as ground truth
- Tests must not call the live API

## 2026-08-22 - US-002
Model-assisted pre-labeling CLI.
- Added src/prelabel.py, src/cli.py, tests/test_prelabel.py (12 tests, all passing)
- Adjudication logic separated from I/O via an injected prompt_fn, so it tests
  without a TTY and without any live API call
- Unrecognized input DEFERS rather than accepts: a mis-keyed label is worse than
  an unresolved one
- apply_adjudication UNIONS accepted names into expected; it must never replace,
  since a case may already carry hand labels
- Provenance written to expected.prelabel on every touched case so the assist can
  be disclosed in the writeup

**Learnings for future iterations:**
- pyproject sets asyncio_mode, which warns unless pytest-asyncio is installed --
  it now is
- Candidate.evidence_flag reuses evidence_is_verbatim/evidence_similarity from the
  set grader; do not write a second verbatim checker
- The CLI loads .env itself via load_env(); scripts/ have their own copies of this
  loader, worth consolidating when US-011 lands

## 2026-08-22 - US-003
Config loader and the four YAML configs.
- Added src/config.py, configs/{baseline,structured,cheaper,regressed}.yaml,
  prompts/structured.md, prompts/regressed.md, tests/test_config.py
- 35 tests total passing
- Pricing lives IN the config, not in code, so the cost/quality chart regenerates
  identically from a committed results file after list prices change
- Cache prices default to documented multipliers (0.1x read, 1.25x write) and can
  be overridden per config
- Loader validates that the prompt contains the {{DOCUMENT}} placeholder -- a
  silent no-substitution bug would otherwise send the literal template to the API

**Learnings for future iterations:**
- configs differ on exactly ONE variable each: baseline->structured is the prompt
  plus output_config.format; structured->cheaper is the model alone. Tests assert
  this. Do not let a future config change two things at once.
- regressed deletes the "What does NOT count" section and the empty-array example
  from structured, but KEEPS the evidence rules -- otherwise US-010 would be
  testing two regressions at once
- Pyright flags src.* imports in tests/ as unresolved; extraPaths is set in
  pyproject and pytest resolves them fine. Lint-only noise, do not chase it.

## 2026-08-22 - US-004 (+ competitor drift tooling)
Set grader tests, and a real normalization bug they caught.
- Added tests/test_set_grader.py; 72 tests total passing
- Added scripts/competitor_drift.py -- diffs a company's named competitors across
  successive 10-K filings. Real SEC filings only, nothing generated.
- BUG FOUND AND FIXED in normalize_name: parenthetical glosses and slash pairs
  defeated it. "International Business Machines Corporation (IBM)" vs "IBM" and
  "Broadcom/VMware" vs "Broadcom" each read as a drop plus an add. HPE drift churn
  was inflated 50%->43% and 30%->24% by this alone.

**Learnings for future iterations:**
- The drift tool is a grader test in disguise: running the same grader over three
  years of one company surfaces normalization failures that fixed test fixtures
  do not. Consider it before trusting any set-grader number.
- Third instance of the same lesson: the harness manufactures its own findings.
  Pagination artifacts cost 14 points of verbatim accuracy; parenthetical
  renderings cost 7 points of churn. Check the grader before blaming the model.
- Juniper Networks legitimately left HPE's competitor list because HPE acquired
  it. Ground truth moves for reasons no prompt can fix -- this is the concrete
  example for the golden-set-maintenance section of the writeup.

## Codebase Patterns
- Use ./.venv/bin/python, not bare python3
- Harden the spike code; do not rebuild it
- Never treat spike-quality labels in data/cases/ as ground truth
- Tests must not call the live API

## 2026-08-22 - US-004 (+ competitor drift tooling)
Set grader tests, and a real normalization bug they caught.
- Added tests/test_set_grader.py; 72 tests total passing
- Added scripts/competitor_drift.py -- diffs a company's named competitors across
  successive 10-K filings. Real SEC filings only, nothing generated.
- BUG FOUND AND FIXED in normalize_name: parenthetical glosses and slash pairs
  defeated it. "International Business Machines Corporation (IBM)" vs "IBM" and
  "Broadcom/VMware" vs "Broadcom" each read as a drop plus an add. HPE drift churn
  was inflated 50%->43% and 30%->24% by this alone.

**Learnings for future iterations:**
- The drift tool is a grader test in disguise: running the same grader over three
  years of one company surfaces normalization failures that fixed test fixtures
  do not. Consider it before trusting any set-grader number.
- Third instance of the same lesson: the harness manufactures its own findings.
  Pagination artifacts cost 14 points of verbatim accuracy; parenthetical
  renderings cost 7 points of churn. Check the grader before blaming the model.
- Juniper Networks legitimately left HPE's competitor list because HPE acquired
  it. Ground truth moves for reasons no prompt can fix -- this is the concrete
  example for the golden-set-maintenance section of the writeup.

## 2026-08-23 - US-006
Judge grader for prose only.
- Added src/graders/judge_grader.py, prompts/judge.md, tests/test_judge_grader.py
- 121 tests passing, 1 deselected (the live cache test)
- Rubric grades faithfulness/relevance/concision 1-5 with all five levels defined
  per axis and three worked examples; tests assert the levels exist so a future
  rubric edit cannot silently drop one
- 3 sequential calls, per-axis median. Sequential is deliberate: the first call
  must land before the others so they hit a warmed cache instead of racing to
  write it. A test asserts all three requests are byte-identical.
- sample_spread exposes the judge's OWN instability per axis -- useful in the
  writeup alongside the extraction noise floor

**Learnings for future iterations:**
- pyproject now defines a `live` marker with addopts = -m 'not live'. Tests that
  need the real API go behind it. Run them with: pytest -m live
- A test asserting rubric phrases failed on a hard-wrapped line. Use flat() to
  collapse whitespace before phrase matching -- same class of bug as the EDGAR
  pagination artifacts, now hit twice.
- The rubric explicitly protects the correct-empty answer. 3 of 5 spike docs name
  no competitors; a judge that penalized a short correct "none" would invert the
  empty bucket.

## 2026-08-23 - US-007
Metrics, bucket breakout, bootstrap CIs.
- Added src/metrics.py, tests/test_metrics.py; 146 tests passing
- Report exposes aggregate AND by_bucket together, plus worst_bucket() which names
  the bucket an aggregate would hide
- bootstrap_ci is seeded (BOOTSTRAP_SEED) so a committed results file regenerates
  identical intervals
- exceeds_noise_floor() is the gate US-010 will use: a drop must clear
  noise_floor x 2, not merely be negative

**Learnings for future iterations:**
- forbidden_rate and verbatim_rate are denominated in EXTRACTIONS, not cases. One
  forbidden hit among 30 extractions is not the same failure as one among one.
- An empty case cites no evidence; verbatim_rate is 1.0 there, not 0.0. Getting
  this backwards would make the empty bucket look like an evidence catastrophe.
- Cached results have latency 0.0 and are excluded from percentiles, otherwise a
  re-run reports a fictional p50.
- A test asserting different seeds give different CI bounds FAILED: at n=5 the
  2.5% quantile lands on the same discrete value. Seed sensitivity is not a
  required property; determinism is. Replaced with a stability test.

- Added src/report.py, tests/test_report.py; 164 tests passing

- Bucket ordering is canonical (clean, ambiguous, adversarial, empty, long) with
  unknown buckets appended, so report diffs between runs stay readable.
